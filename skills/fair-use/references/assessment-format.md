# Assessment format

Use a concise version for a quick question and expand for a significant decision. Request missing essentials before pretending to complete the analysis. No mandatory numerical score.

## Proposed structure

**Assessment:** qualitative category from SKILL.md, the exact use covered, jurisdiction and date. Use one short sentence explaining that this is a preliminary assessment rather than legal clearance.

**What I examined:** files/versions/frames, source works, user statements, license evidence, and current authorities actually checked. Clearly distinguish observed facts from assumptions. Say whether web and visual inspection were available.

**Basis and scope:** permission, ownership, public domain, no identified specific borrowing, a possible exception, or an unresolved basis. Identify unresolved components individually. “No identified source” does not prove originality.

**Reasoning:** for US fair use, a compact four-row table: factor; facts that support; facts that weaken or remain unknown. Follow with a balanced synthesis. For another country use the appropriate local framework, or state the coverage gap.

**Separate issues:** only relevant license/contract, authorship, trademark, likeness or other concerns. Do not mix a platform usage rule with the statutory copyright test.

**What would change the assessment:** material missing facts, contrary evidence, publication context, source ownership or license terms.

**Practical next step:** specific evidence to obtain, revision tied to the concern, suitable permission or alternative asset, or qualified local counsel if warranted. Include primary citations close to the claims they support and a source-check date.

## Example intake message

“I can assess the arguments, but an image alone cannot establish fair use. Please provide the relevant country, what you plan to do with it, and the source image or license if there is one. Tell me what was copied or uploaded. If you only have the finished image, I can start with that and explain the limits.”

Do not ask for an existing source when the user has already said the work was independently created without one. Do not demand sensitive originals where a sufficient description or redacted version would answer the question.

## Example conclusion style

“For the proposed US sale of decorative prints, the fair-use argument appears weaker on the supplied facts. The image has been restyled, but the stated purpose remains decorative reproduction. The original and exact retained elements have not been inspected, so this is conditional. A suitable license or a design built from independently created material would address the identified concern more directly than additional filters.”

This invented example demonstrates phrasing; it is not a legal result or an assessment of an uploaded image.
