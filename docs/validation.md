# Validation status

Release candidate 0.1.0 · September 7, 2026

This document distinguishes package integrity, AI behavioral testing, and legal expertise. None of them substitutes for the others.

## Structural verification

The repository includes a frontmatter/reference checker and a packaging verifier. The ZIP uses an explicit seven-file skill allowlist plus the repository license. The standalone chat file is generated from the same canonical instructions and references, with internal links converted into attachment anchors. The build also emits SHA-256 checksums.

The bundled skill-creator validator passed. Repository frontmatter, local links, license, metadata and twelve case definitions passed structural checks. The ZIP's eight entries were checked against canonical bytes, and a separate temporary build produced byte-identical ZIP, chat attachment and checksums. The public file inventory was checked for unrelated/private files and personal absolute paths. These checks do not validate legal conclusions.

## Independent AI review

An independent GPT-5.6 Sol reviewer applied the first draft to three text-only scenarios: an AI-restyled Etsy poster, a mixed-source Canva template, and a Canadian business post presented as US fair use. The reviewer checked live primary sources and recorded responses. No images or actual licenses were supplied.

The observed responses avoided guaranteed clearance, a percentage-change rule, blanket permission from Canva Pro, and treating US factors as Canadian clearance. The review identified research-workflow gaps. The draft was revised to add CCH and additional US source pointers, archived Canva-term handling, template-delivery distinctions, cross-border routing, and legal-publication caution.

This is a small qualitative AI review, not a measured accuracy rate or validation by a lawyer. The twelve cases in the repository are test definitions; the structural checker does not run them through a model.

A follow-up review checked the revisions and applied two additional text-only scenarios: an authentic license covering the proposed brochure, and an essay analyzing a poster's typography. The responses appropriately identified permission as a separate basis and a plausible conditional fair-use argument for criticism. Across the five exercised scenarios, the reviewer found no release-blocking issue. This is not a claim that all twelve fixtures or all jurisdictions were tested.

The reviewer also inspected packaging and checksums. Two maintainability points were addressed: validation now refuses Python optimization mode (which would disable assertions), and the chat attachment reads its source-review date from the canonical register rather than an independent hard-coded date.

## Coverage limits

Actual image comparisons, client disputes, independent attorney review, and end-to-end uploads in ChatGPT or Claude accounts have not been tested. The standalone file and ZIP follow documented structures; host acceptance and capabilities can differ. Detailed jurisdiction coverage remains US-focused, with Canadian and UK routing notes.

The source register records research completed on September 7, 2026. Source availability varies by browser and region; Canadian court endpoints returned access errors in some retrieval attempts, while indexed primary-source text supported the cited CCH passage. A user assessment must disclose any retrieval failure and must not turn the package's source date into a claim of current verification.
